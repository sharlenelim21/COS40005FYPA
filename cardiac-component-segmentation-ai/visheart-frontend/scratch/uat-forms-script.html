UAT Questionnaire — Forms Copy Sheet

Everything below is written to be copy-pasted straight into Microsoft Forms: one section per block, in order, with the exact title, subtitle, question text, and recommended Forms question type.

01

In Forms, click + Add new → Section for each block below, then paste its title and subtitle.

02

03

For Likert blocks, add all listed statements as rows under one Likert question, with columns 1–5 as shown.

Tick everything you did before filling in this form. This helps us weigh your later answers correctly — for example, skip Section D's accuracy questions if you didn't run that feature.
Questions

One question, type Choice (allow multiple selections) — title it "Which of the following did you do?" — with these options:

  • Uploaded / selected an MRI case and ran segmentation (UNet or MedSAM)
  • Manually corrected a segmentation mask
  • Built a 4D reconstruction (LV and/or RV)
  • Ran landmark detection and reviewed/edited points
  • Computed Quick (ED→ES) strain
  • Computed full-cycle (all-frame) strain
  • Explored the Structure tab (wall thickness, 3D heart)
  • Explored the Strain tab (bullseye + 3D heart colouring)
  • Viewed / exported a PDF report

Section D
Title
Strain & RV Analysis
Subtitle
The core contribution of this project — please answer in as much detail as you can. Only skip an item if you did not complete that task in Section A.
Questions Likert

This is the largest/most important section — split across two Likert questions (23–27, 28–33) to keep each block readable.

  1. The auto-detected landmark points (ED/ES, insertion points) were close enough to where I would place them.
  2. Adjusting a landmark point (drag to correct) was easy and responded smoothly.
  3. LV strain values (GCS/GRS) seemed consistent and physiologically plausible across the cardiac cycle.
  4. RV strain values (GCS/GAS/FAC) seemed consistent and physiologically plausible across the cardiac cycle.
  5. The RV bullseye/9-segment regional breakdown was clear and matched what I'd expect from the RV shape shown.
  6. The RV and LV results agreed with each other where I'd expect them to (e.g. colouring, segment highlighting, 3D model sync).
  7. Full-cycle (all-frame) strain curves were smooth, with no implausible jumps between neighbouring frames.
  8. I trust the strain/RV numbers this software produces enough to use them in a clinical/research discussion.
  9. The 4D reconstructed mesh was a reasonable basis for the strain computed from it (shape roughly matched the MRI slices).
  10. The PDF report presented the strain and RV findings clearly, and matched what I saw on screen.
  11. The report's interactive elements (hover/slider on charts, clickable segments) were useful for reviewing results.
